安装依赖，node 为 26.8.2

```bash
cd front
nvm install
nvm use
npm install -g pnpm@9.14.4
pnpm install:all
cd ..
```

如果需要改请求地址，在 `front/blog-web/profiles.config.mjs` 的 `site.url`。
不设置 `PUBLIC_API_BASE_URL` 的情况下，默认请求同源 `/api`，然后通过服务端 `nginx` 代理到后端 8080 端口。

构建产物：根目录下执行 `pnpm --dir front/blog-web build:main`
获取产物：`front/blog-web/dist/main` 下面文件，产物包含页面、`_astro/` 和 `pagefind/`，需要完整上传。

部署到后端机器，Nginx 监听 80，后端使用 8080。
