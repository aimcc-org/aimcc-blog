# 用户偏好 Skill

## 何时使用

每次对话开始时阅读，了解用户的沟通方式和技术约定。

## 沟通方式

- Java 新手：术语要解释，遇到新概念先讲清楚再写代码
- 喜欢先讨论方案细节、给「选项 + 推荐 + 理由」由他拍板
- 节奏：一个模块一个模块，每步讲清「在干嘛、为什么」
- 教学形式是本项目的核心目的：AI 代写要克制，代码尽量让用户自己写，AI 负责讲方案、review、编译验证；用户会主动要求回归教学模式，别默认全代写
- 效果好的教学流程：讲方案 → 用户照敲 → AI review → 编译验证 → 用户浏览器验证。review 环节别省
- 数据库操作教学式：SQL 给用户自己在 DBeaver 执行，他不习惯命令行直接跑
- 用户环境：MySQL 密码在 IDEA 运行配置环境变量 DB_PASSWORD；DBeaver 管理数据库；IDEA 装了中文插件（指导操作时用中文菜单名）

## 技术约定

- Spring Boot 版本 4.1.1，给配置/异常类必须按此版本，不给旧版本写法
- 代码风格：避免链式调用，用显式循环 + 分步中间变量
- VO 字段恒 private，访问靠 getter/setter
- Controller 注入用 final + @RequiredArgsConstructor
- SQL 关键字写进项目用大写，教学讲解用小写
